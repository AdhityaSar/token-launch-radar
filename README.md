Peer-calibrated pre-token launch radar and costed DeFi farm planner. Calibrates sector MCap/TVL multiples from 108 live-token DeFi comparables via log-space Empirical-Bayes shrinkage and builds chain-aware, costed, timed 6-step farm plans for all 40 watchlist protocols and 138 early-stage pre-token protocols.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
